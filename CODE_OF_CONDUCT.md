# Code of Conduct

Contributors should be respectful, constructive and considerate. Harassment, discrimination, threats, sexualized conduct and sharing private information without consent are unacceptable in project spaces.

Report concerns privately to a maintainer through their GitHub profile or request a private channel without posting sensitive details in a public issue. Maintainer EthTobi may remove abusive content and restrict participation. Reports should be handled with discretion and conflicts of interest disclosed; no response-time guarantee is made.
